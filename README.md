# IconUp Agency

Bilingual (DE/EN) landing page for IconUp, built with Next.js App Router.

## Positioning
IconUp turns digital artists into real brands.

## Features
- German / English language switch with saved preference
- Responsive editorial landing page
- Artist-brand positioning
- Contact form for talent, booking, brand, business and press enquiries
- Talent types are only shown in the contact flow: songwriter, producer, rapper, vocalist
- SEO and OpenGraph metadata

## Local development
```bash
npm install
npm run dev
```

## Contact form
The current V1 submits through the visitor's email client to `hello@iconup.agency`. For production, connect the form to your preferred email/form backend.

## Deployment
Optimized for deployment on Vercel.
